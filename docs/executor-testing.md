## Invariants

- **A "denied" assertion run against a CNI that does not enforce NetworkPolicy passes vacuously.** That is why
  `--netpol` owns its own Calico cluster, and why it runs an **honest-probe control on every denial target**: each
  must answer `reachable` before the policy and `denied` after.
- **Platform-parity cases are not duplicates.** A contract encoded in both docker argv and Kubernetes object specs keeps
  both pins; consolidate only when setup, branch and expected failure are identical.
- **The focused coverage gate excludes `driver/src/index.ts`, `driver/src/scripts/` and the Postgres telemetry
  store** (`vitest.executors.config.ts`); the script suites and `test:db` cover them.

## What no lane covers

- **Two dashboard replicas on a cluster.** The chart defaults to one (`charts/factory/values.yaml`),
  so the kind capacity phase runs one board; `server/test-db/job-store.fairness.test.ts` runs the claim from two connections.
- **`npm run test:jobs` on a Linux docker daemon.** Its compose-driver and question-round-trip phases need
  `host.docker.internal` (`assertNoneModeBindable`, `server/src/config.ts`); the lane is not in CI ([ci.md](ci.md)).
- **The real collector**; **a cloud cluster** (`--cluster` refuses every non-kind context; [eks-runbook.md](eks-runbook.md));
  **fault injection in the kind phase** beyond `scripts/test-k8s.sh`'s disruption, takeover and drain phases;
  **a real agent CLI honouring the master prompt's flags**; **allowlisted block helpers under `--cluster`**.
- **The cloud metadata endpoint (169.254.169.254) is not probed.** Nothing answers on it in kind, so a probe could only
  report `denied` — the vacuous pass above. The lane proves the mechanism: `169.254.0.0/16` is a `blockedCidrs`
  entry excluded from the same `0.0.0.0/0` egress rule the node probe shows dropping traffic.
- **IPv6, cross-attempt isolation, DNS shadowing** — [kubernetes.md](kubernetes.md). **Task-level workspace isolation**
  — [workspace.md](workspace.md). **Kernel isolation** is claimed nowhere ([security.md](security.md)).
