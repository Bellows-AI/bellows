# Job board

A job is a text command a worker runs as an agent prompt; the board leases jobs out and records
verdicts, and the driver is the only process that spawns anything. Graphs are
[workflows.md](workflows.md), the kubernetes executor [kubernetes.md](kubernetes.md), credentials
[auth.md](auth.md).

## Invariants

- **A declared `.bellows.yaml` service runs hardened, which breaks stock images that expect root.**
  A stock postgres chowns its data directory as root at first boot and crash-loops; `user: "uid:gid"` is the
  fix, and there is no opt-out: the board refuses `unhardened` at parse. `server/src/workspace/bellows-services.ts`,
  `server/test/bellows.plan.test.ts`, [security.md](security.md).
- **A run reports agent turns**: the close-time agent-turn read counts the executor's own transcript; a job turn
  is in [docs/metrics.md](metrics.md). Null is the contract for unmeasured. `core/test/docs.terminology.test.ts`.
- **A `409` from heartbeat means the container must be killed**; `cancelRequested` during the agent's run
  drains to the next step boundary instead. `driver/test/loop/`.
- **Every resource an attempt creates is scoped by its lease token**, so no sweep touches a sibling
  attempt — `driver/src/labels.ts`, `driver/test/docker/`. On docker each also carries the board's
  `factory.board`, the only objects that board's reaper scans — `driver/test/docker-reaper-boards.test.ts`.
- **A node loss never spends the poison interruption budget** (BEL-302): a release flagged `nodeLoss` is accepted past a spent poison budget, refused only once `NODE_LOSS_BUDGET` flagged entries fall inside `NODE_LOSS_WINDOW_MS`; unflagged entries, lease expiries included, keep counting, and a retirement logs which rule ended the row — `server/test-db/job-store.interrupt.test.ts`, `server/test/routes.jobs.test.ts`.
- **A supervisor lost under a publish is an interruption, never `publishFailed`** (`stepLost` is rethrown by `publishCheckout` and `publishBranch` in `loop-publish-retry.ts`, ended in `loop-post-run.ts`) — `driver/test/publish-reconcile.test.ts`, `loop/`.
- **A publish re-asks the board for a GitHub token and retries (3 tries) a missing or rejected token or a GitHub 5xx**, never a refusal, conflict or stale revision; fenced before each ask and push, a bound revision followed across its own commit by content — `publishWithRetry` in `driver/src/loop/loop-publish-retry.ts`, `publishRetryable` in `driver/src/publish/publish.ts`, `driver/test/loop-run.test.ts`, `publish-control.test.ts`, `publish-cause.test.ts`.
- **The publish decision is made in `driver/src/loop/loop-verdict.ts`, `loop-publish.ts` and `loop-publish-retry.ts` only** —
  `driver/test/docker/`, `k8s/`.
- **A decided verdict is staged, then completed, and only then is the attempt torn down**; it is retried on
  5xx and never rewritten — `driver/test/loop/`, `board-retry.test.ts`.
- **A null `masterPrompt` on the wire is refused before setup**, and the render never reads command,
  output or env values — `driver/test/master-prompt.test.ts`, `server/test/master-prompt.test.ts`.
- **The executor label resolves at claim in the task's stamped scope**; a missing profile fails the
  task rather than defaulting — `server/test-db/job-store.executor-scope.test.ts`.
- **A runner group whose driver is lost ends inside its lease** (`orphanBoundMs`, `driver/src/supervisor-plan.ts`) and
  is adopted; lost before `go` it exits `SUPERVISOR_EXIT.lost` and is redone; a released group waits `takeoverBoundMs`
  for a newer holder — `driver/test/supervisor.test.ts`, `driver/test/k8s/`.
- **The CLI needs `FACTORY_URL` or `url` in `~/.bellows/settings.json` / `--config <path>`** (no default; `cli/src/config.ts`); run it as `npm run dev -w cli -- job list`. Exit `0` means the verdict `succeeded`, never that a PR is ready (`cli/src/outcome.ts`).

## Stated limits

- Ad-hoc gate runs are not evidence for a publication: under `policy: gates: required` a draft is refused. The close-time pass only reuses a full unfiltered pass; a deliberately backdated mtime defeats its mutation guard, a git-ignored file a gate reads is not part of the content it certifies, and the ad-hoc call's probes add to its 10-minute cap.
- A reviewer profile grants connections and a budget, not a tool allowlist; snapshot refs
  (`refs/factory/review/*`) are never deleted.
- Admission budgets count board leases, not pods; a rollout runs each replica's values. Org fairness is eventual:
  polls reading the same demand at once may serve one org; the next free slot goes to the other. A poll whose claim the global budget refused admits nothing from later boards (takeovers aside). Reclaims rotate.
- Attachments have no OCR: a scanned PDF yields no text (`unreadable`, `no_text`) and an image is read only by the model. OpenCode reads image attachments only with a vision-capable model; the prompt marks image entries so an agent that cannot see one says so.
- No priority; no per-job authorization ([repos.md](repos.md)); no service volumes, health checks,
  `depends_on` or restart policies in `.bellows.yaml`.
- Skill precedence differs by layer: listings and the board use built-in < org < repo < workspace (a non-built-in `factory-*` name never wins over the built-in), but opencode loads a repo skill over a same-name built-in at run time (claude keeps the built-in); a repo skill missing from the checkout at run time is not detectable by the board (`docker/opencode-executor/test.sh`, `scripts/test-jobs.sh` phase `repo-skills`).
- No abort for an in-flight publish; the next lease holder reads the ledger and the remote first. A custom
  `RUNNER_IMAGE` missing a skill's declared tool is not detected.
- Only the tail-kept log and the opencode transcript upload whole-or-cut (`ARTIFACT_LIMIT`); no sweeper
  deletes a removed task's run-artifact objects (attachments are swept) (`driver/src/runner.ts`, `k8s-transport.ts`).
