09 / QUESTIONS, ANSWERED

The practical details.

Is Bellows Cloud available today?

We're engaging early-access teams and design partners. Send us your use case and we'll discuss pilot scope, timelines and what can be supported. We don't claim general availability yet.

Is Bellows open source?

Yes. The Bellows control plane has an open-source repository and a self-hosted path. Bellows Cloud is the managed service we're developing around it.

Which coding agents does it support?

The open-source project currently documents Claude Code and OpenCode as first-class executors. We'll confirm the exact integrations available for your Cloud pilot.

Can a product manager use Bellows from an AI chat?

That is the experience we are building for Bellows. The planned MCP connector will be open source, so teams can run it themselves or use it via managed Cloud. It will let a chat initiate repository work, run checks and return reviewable outcomes. This integration is not generally available yet. Discuss a pilot to help shape it.

Does it replace developers, or work only for new apps?

No. Brownfield systems are the point: existing repositories, dependencies, business rules and tests. Product teams request scoped changes; engineers focus on architecture and difficult technical work while retaining review, approval and release decisions.

Can engineers enforce architectural standards?

Bellows already supports versioned repository-defined workflows and quality gates in .bellows.yaml, with agent execution and review stages. Architecture policy checks, risk-aware review routing and reusable golden paths are roadmap ideas, not generally available features today.

How are quality and security handled?

Workflows can include test, review and human approval stages. The self-hosted stack documents remote Docker or Kubernetes execution. Security boundaries, data handling and deployment requirements are defined with each pilot, rather than implied as universal guarantees.

Is MCP only available in Bellows Cloud?

No. Our plan is to build MCP chat integration in the open-source Bellows project too. You can self-host it. Bellows Cloud is the paid managed option for teams that would rather have us operate the infrastructure, upgrades, monitoring and support.

What does the Cloud subscription pay for?

Managed execution and orchestration infrastructure, deployment, maintenance, monitoring, onboarding and support. The open-source features are not locked behind a hosting paywall. Exact scope, availability and pricing are agreed during early-access pilots.

What about Enterprise SSO and advanced auditing?

SSO, more granular permissions, expanded audit and governance controls are planned Enterprise capabilities. They are not presented as shipping today. We are collecting security and compliance requirements from prospective teams for a managed or separately agreed self-hosted deployment.

How does Cloud pricing work?

We are validating managed-service and support packaging with early teams. Pricing may combine a platform subscription and infrastructure usage; Enterprise requirements are discussed separately. No fixed public price has been announced here.
