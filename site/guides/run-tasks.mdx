## Create a task

Click **New task**. Describe the change, then pick the repository and [executor](/guides/executors). You can also [attach files](/guides/attachments) (images, PDF, docx, txt, md, csv; up to 20 MiB each) and add [connections](/guides/connections). Press **Start task** or `⌘ + Enter`.

## The inbox

**Tasks** has three tabs. **Needs attention** holds everything waiting on you: answers, reviews and failures. **Running** is work in progress. **Past** is finished work. Filter by repository or person, or search task requests.

## Task actions

| Action                    | When to use it                                                                                     |
| ------------------------- | -------------------------------------------------------------------------------------------------- |
| **Follow up**             | The run finished, but you want more or something different. Same checkout, executor and session    |
| **Answer**                | The agent asked a question                                                                         |
| **Retry**                 | The run failed for a transient reason; same prompt, new job                                        |
| **Edit**                  | You'd rather fix the prompt than add to it                                                         |
| **Stop**                  | The run is going the wrong way                                                                     |
| **Mark done** / **Reopen** | Close the task in Bellows; it doesn't merge or close the PR. Reopen to continue later             |

What each status means, and what to do when a run fails: [Task lifecycle](/guides/task-lifecycle).
