description: "Remote agentic engineering platform: a coding agent runs in an environment your repository defines and must pass your checks."
---

Bellows is a remote agentic engineering platform. It runs a coding agent against your repository in a remote runner, so every run starts from the same environment:

- **Defined environment.** The runner's image, setup commands, caches and services come from `.bellows.yaml` in your repo.
- **Required checks.** Gates (build, test, lint) run at the end of every job; a pull request is published only when all of them pass.
- **Reviewable result.** The output is a pull request you review. Questions, follow-ups and retries continue the same task.
- **Recoverable runs.** If a node or runner is lost, the task resumes its session and checkout instead of starting over.

## Cloud or self-hosted

|          | Bellows Cloud                                    | Self-hosted                                  |
| -------- | ------------------------------------------------ | -------------------------------------------- |
| Setup    | Sign in with GitHub, pick repos, connect a model | Postgres, a GitHub App, Docker or Kubernetes |
| Runners  | Managed                                          | Your cluster (Helm chart)                    |
| Data     | Bellows Cloud database                           | Your Postgres                                |

<Note>
  These docs follow the Cloud path. To run Bellows yourself, see [Self-hosting](/self-host/overview).
</Note>

## How it fits together

| Part         | What it does                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------------- |
| **Server**   | Stores tasks and serves the web app, the API and the MCP endpoint                                   |
| **Driver**   | Picks up queued jobs and starts a runner for each one                                               |
| **Runner**   | The container your repo's `.bellows.yaml` describes. The agent works and the gates run here          |
| **Executor** | The coding agent: Claude Code, OpenCode or a custom profile built on them                          |
